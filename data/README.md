# Data

The datasets used in the manuscript are not stored in this repository. They are archived on Zenodo:

**https://doi.org/10.5281/zenodo.23388462** (CC BY 4.0, 159 MB in total)

## Download

From the repository root:

```bash
python data/fetch_data.py                 # all six archives
python data/fetch_data.py isfet_data env_monitoring    # only some of them
```

The script downloads each archive from the Zenodo record and unpacks it into this folder. You can also download the `.zip` files by hand from the record page and unzip them here.

## Contents

| Archive on Zenodo | Size | Used for | Read by |
|---|---|---|---|
| `isfet_data.zip` | 31 kB | Fig. 3, Supplementary Figs. 1–2 (ISFET H⁺, Na⁺, K⁺ channels and the reference probe, daily means) | `examples/isfet_data_v3.py`, `examples/si_isfet_na_k.py` |
| `gas_sensor_worner2025.zip` | 147 MB | Fig. 4, Supplementary Figs. 3–4 (MOX electronic-nose record) | `examples/gas_data_v3.py`, `examples/gas_data_v3_si.py` |
| `env_monitoring.zip` | 805 kB | Fig. 5, Supplementary Figs. 5–6, Supplementary Tables 3–5 (stream and reservoir water quality, 2020–2021) | `examples/env_data_v3.py`, `examples/env_sensitivity_v3.py` |
| `flashcrash.zip` | 10.9 MB | Supplementary Fig. 7 (Dow Jones Industrial Average, 23 April 2013) | `examples/flashcrash_data_v3.py` |
| `bond.zip` | 23 kB | Supplementary Fig. 8 (UK 10-year government bond yield) | `examples/bond_data_v3.py` |
| `well-log.zip` | 15 kB | Supplementary Fig. 9 (well-log record) | `examples/welllog_data_v3.py` |

The synthetic benchmark (Fig. 2) and the scaling benchmark (Supplementary Fig. 10) need no data file: the series are generated by `vocd.datasets` from fixed seeds.

## Expected layout

After unpacking, the experiment scripts look for the data here by default (each script also accepts `--data-dir`):

```
data/
├── README.md
├── fetch_data.py
├── isfet/               h_mv.csv, na_mv.csv, k_mv.csv, ref_mv.csv
├── env_monitoring/      2020-21_stream_and_reservoir.xlsx, virginia.geojson
├── gas_sensor_worner2025/
├── flashcrash/          DJI.txt
├── bond/
└── well-log/
```
